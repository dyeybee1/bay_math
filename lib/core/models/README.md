# core/models

Reserved for **shared, cross-feature model contracts** only
(e.g. a common `Result<T>` wrapper, base entity interfaces, enums shared
by multiple features).

This folder is intentionally empty in Phase 0. Business entity models
(Student, Teacher, Lesson, Quiz, Question, etc.) are out of scope for this
phase and will be added feature-by-feature under
`lib/features/<feature>/` in later phases, not here.
